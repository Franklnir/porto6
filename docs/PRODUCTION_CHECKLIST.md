# Production Checklist

- [ ] Isi seluruh variabel pada `.env`.
- [ ] Ganti foto placeholder dan file CV.
- [ ] Jalankan `npm install` dan commit lockfile yang dihasilkan.
- [ ] Jalankan `npm run verify:full`.
- [ ] Periksa desktop 1440×900, laptop 1366×768, tablet 768×1024, dan mobile 390×844.
- [ ] Pastikan tidak ada horizontal overflow.
- [ ] Periksa keyboard navigation, focus state, dan reduced motion.
- [ ] Jalankan Lighthouse pada production preview.
- [ ] Deploy preview ke Vercel dan Cloudflare sebelum domain produksi diarahkan.

BAGIAN 01 : RINGKASAN EKSEKUTIF
01 / RINGKASAN EKSEKUTIF

Solusi Terintegrasi Physical AI untuk Kebutuhan Riil Mitra

1. Kondisi & Masalah

Otomasi cerdas dan pemanfaatan AI saat ini didominasi aplikasi berbasis layar yang tertutup, memiliki ketergantungan lisensi cloud berbiaya berulang, serta minim media praktikum hardware mandiri yang dapat dibedah oleh institusi pendidikan dan korporat.

2. Solusi Xichi AI

Xichi AI Studio menghadirkan perangkat kecerdasan fisik (*Physical AI*) berbasis mikrokontroler ESP32-S3 dengan kemampuan dialog suara natural bahasa Indonesia, arsitektur server fleksibel, serta integrasi 47 modul perkakas cerdas (*MCP Tools*).

3. Nilai Bisnis & Operasional

Meningkatkan efisiensi kerja melalui otomasi asisten fisik di meja kerja, menyederhanakan kontrol perangkat kelistrikan via relay, dan menyediakan kurikulum praktikum IoT/AI siap terap tanpa royalti vendor asing.

4. Target Pengguna

Laboratorium universitas, SMK/vokasi jurusan elektronika & RPL, divisi teknologi perkantoran, pengelola smart building, serta praktisi riset tertanam (*embedded engineering*).

5. Bentuk Kerja Sama

Pengadaan unit fisik bergaransi (kit maupun *ready-to-use*), implementasi perangkat asisten kantor, workshop transfer pengetahuan teknis, serta opsi kustomisasi perangkat lunak dan casing.

6. Deliverables Diterima Mitra

Unit perangkat keras lulus uji *Quality Control* (QC), build firmware siap pakai, modul ekspansi (opsional), panduan penggunaan, sesi pelatihan instruktur, serta layanan purna jual resmi.

Proposal ini mencakup solusi perangkat, integrasi perangkat lunak, konfigurasi awal, dokumentasi, pendampingan teknis, serta opsi pengadaan dan kustomisasi sesuai kebutuhan mitra.

VALUE PROPOSITION UNTUK MITRA

Pemberdayaan Teknologi Riil Lintas Sektor

1. Efisiensi Pengadaan

Solusi siap operasional dengan biaya terjangkau dibanding perangkat pintar impor tertutup.

2. Media Lab & Riset

Perangkat terbuka yang mendukung riset firmware, sensorik audio I2S, dan integrasi API AI.

3. Fleksibilitas Kustomisasi

Dukungan personalisasi nama asisten (*wake word*), instruksi sistem (*prompt*), dan casing modular.

4. Integrasi IoT Fisik

Kendali langsung peralatan listrik via protokol MQTT, relai 220V, dan telemetri sensor lingkungan.

5. Kemandirian Sistem

Arsitektur yang dapat diarahkan ke server mandiri/lokal guna menjaga kedaulatan data internal mitra.

6. Pendampingan Teknis

Dukungan langsung dari tim pengembang mencakup panduan integrasi, manual book, dan garansi resmi.

BAGIAN 05 : PAKET PENGADAAN
05 / PAKET PENGADAAN & IMPLEMENTASI

Paket Kemitraan, Ruang Lingkup & Timeline Pelaksanaan

1. Paket Edukasi & Lab Praktikum KAMPUS & SMK

Tujuan: Kurikulum praktik hands-on mikrokontroler, IoT, dan embedded AI.

  • Komponen: 10x Xichi Kit (DIY) atau Xichi Core, modul kabel & sensor dasar.
  • Deliverables: Modul pembelajaran praktikum PDF, panduan unboxing, repositori open.
  • Layanan: 1x Webinar/workshop pengantar 2 jam bagi dosen/instruktur lab.
  • Opsi Kustomisasi: Penyesuaian silabus dan tugas akhir mahasiswa.
2. Paket Kantor & Produktivitas PERKANTORAN

Tujuan: Asisten meja kerja interaktif staf dan otomasi resepsionis front-office.

  • Komponen: 5–15 unit Xichi Core ready-to-use, adaptor resmi, stand meja.
  • Deliverables: Unit terkalibrasi, kartu petunjuk perintah operasional kantor.
  • Layanan: Konfigurasi awal jaringan Wi-Fi kantor dan pendampingan setup.
  • Opsi Kustomisasi: Persona asisten kantor dan logo instansi pada bodi unit.
3. Paket IoT & Smart Building FASILITAS

Tujuan: Integrasi kendali kelistrikan gedung, lampu lab, dan telemetri suhu.

  • Komponen: Unit Xichi Core + Bundling Modul Dual Relay Smart Home AC 220V.
  • Deliverables: Diagram kelistrikan aman, konfigurasi topik broker MQTT lokal.
  • Layanan: Panduan teknis pengujian respon saklar dan penanganan beban relay.
  • Opsi Kustomisasi: Integrasi ke sistem otomasi Home Assistant / broker internal mitra.
4. Kustomisasi Merek & Co-Branding ENTERPRISE

Tujuan: Pengadaan perangkat beridentitas khusus untuk cinderamata atau produk mitra.

  • Komponen: Pengadaan unit minimum order tertentu, warna casing kustom.
  • Deliverables: Emblazoned logo lembaga, box kemasan kustom (opsional).
  • Layanan: Penyesuaian nama panggilan asisten (*wake-up prompt*) dan respon khas.
  • Opsi Kustomisasi: Desain enclosure khusus dan sertifikat orisinalitas.
